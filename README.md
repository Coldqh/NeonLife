# NEON LIFE 0.39.2 patch

Патч **City Fabric & Venues** устанавливается поверх `0.39.1`.

Он исправляет физическую структуру локального города: здания размещаются в стабильных участках у уличной сетки, клики обрабатываются единым hit-test, а коммерческие дома получают реальные помещения и сотни заведений с названиями, категориями, графиком, спросом, персоналом и отдельными профилями.

Изменения перечислены в `PATCH_0.39.2.md`. Архив содержит только новые и изменённые файлы.

## Установка

Распакуй архив поверх корня проекта либо запусти:

```powershell
powershell -ExecutionPolicy Bypass -File .\APPLY_PATCH.ps1 -ProjectRoot C:\NeonLife -RunChecks
```

Ручная проверка:

```powershell
cd C:\NeonLife
npm install
npm test
npm run build
npm run dev
```
