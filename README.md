# NEON LIFE 0.35.0 patch

Патч устанавливается поверх `0.34.0`.

1. Распакуй содержимое ZIP в корень проекта `C:\NeonLife` с заменой файлов.
2. Открой PowerShell в корне проекта.
3. Выполни:

```powershell
npm install
npm test
npm run build
```

Изменения перечислены в `PATCH_0.35.0.md`. Архив содержит только новые и изменённые файлы.
