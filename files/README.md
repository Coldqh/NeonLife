# NEON LIFE 0.50.0 patch

Патч **Simple Player Loop** устанавливается поверх `0.49.0`.

Он удаляет старые отдельные системы вакансий, собеседований, контрактов, задач смены и курьерских этапов. Вместо них используется один `playerLoop`: работа одной кнопкой, простые тренировки, снаряжение, быстрые уличные драки и базовая боксёрская карьера.

Работа игрока не копируется в `WorldCore` и не привязывается к случайному бизнесу. Городской рынок труда остаётся автономной фоновой симуляцией.

Изменения перечислены в `PATCH_0.50.0.md`.

## Установка

```powershell
powershell -ExecutionPolicy Bypass -File .\APPLY_PATCH.ps1 -ProjectRoot C:\NeonLife -RunChecks
```
