# Map, Profile & Topology Recovery

## Карта как игровое пространство

`MapScreen` больше не является вертикальной страницей с canvas и диагностической карточкой. Карта занимает рабочую область оболочки, а выбранная сущность открывается через адаптивный sheet.

Локальная карта возвращает типизированный `LocalMapSelection`:

- `location`;
- `building`;
- `stop`;
- `street`;
- `point`.

Интерфейс не выдаёт произвольную точку за доступный маршрут. Начать поездку можно только к существующей `LocationState`, пока отдельная система локального пешеходного движения не реализована.

## Уличные имена

Название линии строится из seed города, ориентации и глобальной координаты оси. Соседние сектора используют одинаковое имя для одной непрерывной улицы.

## Дельты

Дельта улицы считается структурным изменением. Переименование обновляет адрес участка. Удаление сегмента очищает участки, входы и парковки, которые ссылались на него.

## Производительность

`progressLife` сравнивает checksum материализованных секторов и состав парковочной/транспортной сети. Полное выравнивание выполняется только при изменении географии, зданий, остановок или парковочных узлов.
